# 健康重启计划微信小程序

微信原生小程序，覆盖健康档案、指标录入、报告 OCR、计划、打卡、趋势统计和 AI 健康助理。

## 数据规则

- 必须登录账号后使用业务功能。
- 启动时从 `/api/v1/data` 加载当前账号数据。
- 业务数据只保存在运行时内存，每次修改自动写入服务器。
- 网络写入失败时回滚到服务器快照并提示，不使用离线队列。
- Token、用户 ID、头像引用等登录状态可使用微信安全存储。
- 报告图片和头像通过 `/api/v1/files` 上传，由服务端加密后写入京东云私有 OSS。
- 查看文件时通过带 Authorization 的下载接口取得临时文件，不使用 `wx.saveFile`。

## 开发

```bash
npm install
npm test
```

在微信开发者工具中导入项目根目录，实际小程序目录为 `miniprogram/`。所有接口调用统一通过 `miniprogram/utils/http.js`。
